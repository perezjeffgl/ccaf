# Introduction to Agent Skills

Learn how to build, configure, and share Skills in Claude Code — reusable markdown instructions that Claude automatically applies to the right tasks at the right time.

## Main Sections

- **Fundamentals of Agent Skills** — Understanding Skills as reusable markdown instructions and their role in Claude Code
- **Creating Your First Skill** — Building basic Skills from scratch with proper syntax and structure
- **Configuring Skills** — Advanced configuration options, parameters, and customization
- **Distributing Skills Across Teams** — Sharing, collaboration, and version management
- **Troubleshooting Common Issues** — Debugging and resolving common problems
- **Best Practices** — Tips, patterns, and optimization for skill development
